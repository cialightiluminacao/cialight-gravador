# QA da release 1.0.0 → 1.0.1 (18/08/2026)

Máquina: PC do Eduardo (Windows 11 26200, i5-13400, Intel UHD 730, 2 monitores 1920×1080, webcam EMEET SmartCam S600, headset HG04).

## Automatizado (rodado antes do empacotamento)
- `npm run typecheck` (main + renderer): 0 erros. `npm test`: 22 arquivos / 216 testes verdes.
- `npm run test:ffmpeg`: sessão sintética de 4 faixas → proxy/miniaturas/waveform/keyframes; 5 presets exportados e validados por ffprobe (codec/perfil, faststart, duração do corte, tamanho ≤ alvo no preset pequeno, 5 arquivos no preset separado). Encoders detectados: h264_qsv (preferido), h264_mf, libx264.
- `npm run test:capture`: engine real grava 9 s do monitor com loopback + mic + câmera, pausa 2 s, move PiP, registra traço → rec.mp4 com 2 vídeo + 2 áudio, durações coerentes (~7 s), session.json persistido.

## End-to-end na UI (dev build, dirigido por atalhos globais + mouse + CDP)
1. Preparar → `Ctrl+Shift+F9` (contagem 3-2-1 na overlay do monitor gravado) → gravação; `cyclePip` moveu a webcam para o canto inferior-esquerdo; `Ctrl+Shift+F5` + arrasto = caneta; tecla A + arrasto = seta; `Esc`; `Ctrl+Shift+F10` pausa/retoma; `Ctrl+Shift+F1` mute; `Ctrl+Shift+F9` para → Revisão.
2. session.json: 2 keyframes de PiP, 2 traços com tempos de mídia corretos (relógio epoch entre janelas), 1 pausa, 20,6 s.
3. Revisão: proxy + miniaturas + waveform; player com composição; presets com estimativa.
4. Exportações: **Alta** (composição no Worker + h264_qsv): 1920×1080 H.264 High + AAC, 20,6 s, 9,8 MB — frames verificados: PiP no canto correto e traços (caneta + seta) presentes no instante certo; janela do gravador/barra/overlay **ausentes** do vídeo. **Pequeno** (alvo 20 MB): 1,2 MB 720p. **Separado**: tela.mp4, webcam.mp4, mic.wav, sistema.wav, combinado.mkv.
5. Screenshots do desktop com proteção desligada confirmam contagem gigante, borda vermelha, pílula "Modo anotação", paleta e barra flutuante; com proteção ligada nada disso aparece no vídeo bruto.

## Limitações conhecidas (documentadas)
- Modo janela: anotações desabilitadas (o Windows não permite desenhar sobre a janela capturada); menus suspensos e janela minimizada não são capturados (limitação do WGC).
- Sem assinatura de código: SmartScreen na 1ª instalação ("Mais informações → Executar assim mesmo").
- Falha do encoder no meio de uma gravação encerra a gravação preservando o arquivo (fMP4) — o fallback MediaRecorder cobre falhas na inicialização.
- CI do GitHub Actions desligada (token do `gh` sem escopo `workflow`); publicar pelo PC com `npm run release:publish` ou `gh release create` até habilitar.
